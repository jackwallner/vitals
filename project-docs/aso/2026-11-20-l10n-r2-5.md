# Localization ASO upgrade, round 2 batch r2-5: hi, bn-BD, gu-IN, kn-IN, ml-IN, mr-IN (2026-11-20)

Nothing was pushed to App Store Connect. Edits are in `fastlane/metadata/<locale>/` (name, subtitle, keywords, promotional_text, description). Method as in round 1 (`2026-11-20-l10n.md`): Apple `MZSearchHints` per storefront, iTunes Search API for competitors and our rank (trackId 6761743504), Apple's indexing table (https://developer.apple.com/help/app-store-connect/reference/app-information/app-store-localizations; the old URL redirects there).

## Findings that apply to all six

- Indexing (Apple table): India (IND) indexes English (U.K.) as primary and Bangla, Gujarati, Hindi, Kannada, Malayalam, Marathi, Odia, Punjabi, Tamil, Telugu and Urdu as secondary. India does not index en-US. Bangladesh is not a row in Apple's table, and the Bangladesh storefront (143490) returns nothing for any search or hint, English included. So all six locales are really India secondary locales, and the round 1 en-GB keyword field (`tdee,counter,calculator,apple,burned,bmr,deficit,resting,active,pedometer,steps,ring,bmi,intake,move`, name `Total Calories`, subtitle `Kcal Burn on Watch & Widget`) already covers the common English terms in India. These six keyword fields therefore avoid repeating those English words and spend the budget on native-script terms plus a few English words en-GB lacks, split across locales so no two locales repeat the same Latin word (`fitness,health` hi; `weight,diet` bn; `macros,metabolism` gu; `protein,walking` kn; `goal,lock` ml; `siri,csv` mr).
- The live listing (version 1.9.5, `languageCodesISO2A` from the lookup API) includes HI but not BN, GU, KN, ML or MR. A search for our exact current name in Bengali, Gujarati, Kannada, Malayalam or Marathi returns 0 results in IN, while the Hindi name `कुल कैलोरी` returns us at rank 1. So five of the six locales are not indexed by the live version yet, and none of the evidence below can confirm their keywords. They will index once the version that carries them ships.
- Autocomplete: only Hindi shows any native-script demand (below). Bengali, Gujarati, Kannada, Malayalam and Marathi (IN storefront, many seeds each: calorie, step, pedometer, widget, fitness, health, weight, prefixes) return no suggestions in those scripts, and iTunes Search returns 0 results for the same terms. Marathi seeds return Hindi (Devanagari) suggestions, because the two share a script. English terms dominate Indian autocomplete: `calorie tracker`, `calorie counter`, `step counter`, `pedometer`, `fitness tracker`, `health tracker`, `diet tracker`, `weight loss`, `calorie deficit`, `walking step counter`, `calories burned`, `bmi calculator`, `tdee calculator`, `bmr calculator`. All five non-Hindi locales are marked thin evidence.
- Competitor subtitles: apps.apple.com returned a script-only page to curl (same as round 1), so competitor evidence is titles and rating counts only.
- Copy: rewrote every description from the current en-US (the old hi description predated BMI, History views, Net Deficit, TDEE, projections, streaks, excluded days). Same sections and the same not-a-medical-device disclaimer, informal address throughout (आप, আপনি, તમે, ನೀವು, നിങ്ങൾ, तुम्ही), no dashes in prose. The old files mixed spellings inside one locale (ml `കാലറി` vs `കലോറി`, kn `ಕ್ಯಾಲೋರಿ` vs `ಕ್ಯಾಲೊರಿ`); each locale now uses one. The old ml promo had `ലോഗോ`, which reads as "logo"; it now says `ലോഗിങ്ങും`.
- Naming: where the head term (calorie counter, calorie tracker) is owned by food loggers I led with the burn phrase in the other round 1 locales. Here the food-logger vocabulary has no large Hindi competitor, so the name keeps the head term `कैलोरी ट्रैकर` (see hi) and adds `बर्न`. Flagged for Jack: hi, bn-BD, gu-IN, kn-IN, ml-IN and mr-IN names all now read `<Total calories> - <burn> <tracker>`; the old `Daily Tracker` wording is dropped in favour of `Burn Tracker`. Reverting is `git show HEAD:fastlane/metadata/<locale>/name.txt`.
- Name uniqueness: `itunes.apple.com/search` with the exact name, `country=in` and `country=bd`, returned 0 results each time (Indic-script names match nothing else), so no other app has that trackName. Weak check, since the API also returns nothing for the other Indic scripts at all.
- Keyword counts are characters (code points). The repo validator also prints UTF-8 bytes (e.g. hi 241); that is informational and the same as already-live locales (zh-Hans 226).

## hi (Hindi)

- Why picked: India secondary, and the only one of the six that is live in the current listing. India is in both the proceeds list and the downloads list.
- Autocomplete (IN, Hindi seeds): `कैलोरी` -> `calorist: कैलोरी ट्रैकर`, `tola: कैलोरी ट्रैकर`; `स्टेप` -> `stepmate: स्टेप काउंटर`, `pedometer next: स्टेप काउंटर`; `विजेट` -> health and other widget apps; `फिटनेस` -> fitness app / fitness tracker; `हेल्थ` -> health, healthkart, healthify; `ट्रैकर` -> `calorist: कैलोरी ट्रैकर`. No suggestions for `कैलोरी बर्न`, `बीएमआर`, `बीएमआई`, `टीडीईई`, `पेडोमीटर`, `कदम`.
- Competitors: `कैलोरी ट्रैकर` returns 7 apps with 0 to 3 ratings (Snacky, Counter44, MacroHub, NutriLog). `कैलोरी काउंटर` 19 apps, top 28 ratings. `स्टेप काउंटर`: Pedometer α (31k), Pacer (37k), Stepz (3k), StepUp (10k). `पेडोमीटर`: Pedometer α (31k).
- Our rank (IN): `कुल कैलोरी` 1, `पेडोमीटर` 28, `स्टेप काउंटर` not in top 47, `कैलोरी ट्रैकर` not in top 7, `calories burned` 25, `pedometer widget` and `tdee` not in top 46.
- `कैलोरी ट्रैकर` and `स्टेप काउंटर` are the only Hindi demand evidence, and the field is thin, so the name keeps `कुल कैलोरी` (rank 1 now) and `ट्रैकर`, and adds `बर्न` for the burn meaning. Subtitle uses `स्टेप काउंटर` (autocomplete) with `घड़ी` and `विजेट`. Keywords: `पेडोमीटर` (rank 28), `फिटनेस,हेल्थ` and their English forms (autocomplete shows both scripts), `कैलकुलेटर,वजन,डाइट,बीएमआई,बीएमआर,प्रोटीन,कदम,वॉक,घाटा,आराम,लॉक` as category terms. `सक्रिय` left out to fit 100 (en-GB has `active`).
- Name: `कुल कैलोरी - दैनिक ट्रैकर` -> `कुल कैलोरी - बर्न ट्रैकर`
- Subtitle: `TDEE बर्न घड़ी विजेट` -> `घड़ी, विजेट और स्टेप काउंटर`
- Keywords: `पेडोमीटर,bmr,जटिलता,घाटा,विश्राम,सक्रिय,गति,उपवास,चलना,healthkit,गतिविधि,कदम,kcal,bmi,जली,प्रोटीन` -> `पेडोमीटर,कैलकुलेटर,फिटनेस,हेल्थ,वजन,डाइट,बीएमआई,बीएमआर,प्रोटीन,कदम,वॉक,घाटा,आराम,लॉक,fitness,health` (99 chars). Dropped: `जटिलता` (a calque of "complication", nobody types it), `उपवास` (fasting, not a feature), `healthkit`, `kcal`, `bmr`, `bmi` (en-GB covers them).
